# 用户名 + TOTP 登录

状态：用户明确选择服务器命令初始化，不走旧密码登录；实现、隔离验证及独立审查通过；新镜像已暂存，生产待用户真实动态码确认后切换。

用户要求：登录方式改成用户名 + TOTP一次性密码，不要求输入固定密码。

- T1. 完成绑定后，网页登录只提交用户名与身份验证器动态验证码；停用固定密码登录及其回退入口。
- T2. 首次绑定必须验证用户持有身份验证器后才生效，避免先停用旧登录造成锁定；采用服务器命令准备和验证绑定，不走旧密码网页登录。
- T3. TOTP采用兼容身份验证器的6位、30秒周期；允许有限时钟误差，已成功使用的时间步不可重放，服务重启不清除此状态。
- T4. 验证失败限速须持久化，并同时考虑账号与来源；保留HTTPS、安全Cookie、CSRF、会话过期。
- T5. 密钥不写入源码、普通日志、浏览器持久存储或APK；服务端须能验证TOTP，不能像固定密码一样只存不可逆密码摘要。
- T6. 切换成功撤销旧管理员会话；不影响设备独立身份、配置同步和其他管理功能。
- T7. 身份验证器丢失通过具备服务器管理权限的维护流程重置，重置不恢复固定密码登录；具体操作随实施文档交付。

安全边界：此方案是单因素登录，不是密码加TOTP的双重验证；具备密钥的一方可以持续生成验证码。

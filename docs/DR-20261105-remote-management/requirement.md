# DR-20261105-remote-management

状态：需求已确认，书面检查完成；技术方案已于2026-11-05获用户整体批准，代码已实现，验收证据见 [设备验证](../device-validation.md)；生产部署已完成，目标实机仍有未通过项，详见上述证据。
日期：2026-11-05（Asia/Shanghai）。入口：dev-requirement；类型：功能需求；proposal-mode：auto。

## 用户原话

希望把app拥有联网能力，可以实现以下功能：
1. 本地配置同步到远程服务器。
2. 修改远端配置可以推送到本地，实现更新本地配置。
3. 实现版本更新。
4. 远程服务在 server 目录中实现。
5. 记录本地基本状态（启动时间，操作时间）。
6. 远程服务可以重启本机。

## 已确认行为

### 部署、身份与接入

- B1. 本轮交付上述全部六项能力；`server/` 包含远程服务及浏览器管理后台，一个网页管理员账号管理多台设备。
- B2. 远程服务部署于支持 Docker 的 Linux 环境，App 固定连接 `https://ams.opt.work`，不提供 App 内修改服务器地址的入口。
- B3. 网页管理员必须登录后才能管理设备；网页身份验证独立于本机管理密码。
- B4. 设备完成既有首次初始化（Device Owner、密码目录授权、默认密码验证及首次改密）后自动接入服务器；不增加手动绑定步骤或本机解绑入口。
- B5. 自动注册使用部署时配置的接入凭据，服务器为每台设备签发独立凭据；不能仅凭知道服务器地址就获得设备管理权限。
- B6. 完成初始化后，退出本机管理登录、锁屏、重启及关闭管控总开关均不停止远程管理和使用统计；关闭总开关后仍能由远端重新开启管控。网络不可用时继续本地管控与记录。

### 配置与应用目录

- B7. 每台设备独立维护同步配置，首次接入先上传该手机现有配置，再允许网页修改；不得自动以其他设备的配置覆盖新接入设备。
- B8. 同步配置仅包含黑名单、共用周时间表和总开关；本机密码及其校验值、目录授权、设备管理身份不参与配置同步。
- B9. 已登录本机管理员与网页管理员均可修改配置；保存后的本机配置上传服务器，远端变更下发设备并触发本地配置及管控更新。
- B10. 冲突按实际保存配置的更新时间解决：较新的整份同步配置覆盖较旧的，不逐字段合并；更新时间相同则保留服务器版本，不改用服务器收到请求的时间决定先后。
- B11. 设备联网时校准与服务器的时间差，离线继续计时；接受离线并重启后时间未必绝对准确的限制，不承诺可信的全球修改顺序。
- B12. 配置推送在联网且后台连接可用时尽快应用；断网或系统限制后台时显示待同步，恢复后补齐，不承诺锁屏下固定秒数到达。
- B13. 同步供管理使用的应用名称、包名、安装状态及不可管控原因，网页可搜索选择应用编辑黑名单；不上传这些应用的使用行为。
- B14. 远端配置沿用本机周表、保护应用及实际执行结果规则：配置已保存不能等同于系统策略已执行成功，远端操作不得绕过初始化或系统保护边界。

### 系统启动与使用统计

- B15. 记录并在网页显示设备最近系统启动时间；此处启动时间不是管控 App 进程启动时间。
- B16. 使用会话从解锁成功开始，到息屏结束；没有锁屏验证的设备从亮屏且可使用时开始。亮屏后闲置也计入时长，不以真实触摸作为开始或持续条件。
- B17. 每次使用记录包含开始时间、结束时间和持续时长；不采集具体点击内容或各 App 的使用行为。
- B18. 本机与服务端各保留最近90天的使用记录；断网期间本机暂存，恢复联网后补传。
- B19. 网页按设备和日期查看使用明细与每日合计。
- B20. 提供“使用情况访问权”授权入口，用系统仍保留的历史补查遗漏；未授权时继续实时记录，不以该额外授权作为首次初始化必需项。
- B21. 系统漏事件、监测中断等造成且无法可靠补齐的记录须显示“不完整”；不伪造结束时间或精确时长，每日合计提示存在缺失。

### 管控 App 版本更新

- B22. 网页管理员发布管控 App 自身的 APK，选择设备下发升级任务。
- B23. 设备校验升级包后自动安装，无需本机现场确认，保留已有管控配置；网页显示升级结果或失败原因。
- B24. 离线设备的升级任务可以等待恢复连接后执行；不因等待升级而停止已有本地管控。

### 整机重启

- B25. 网页管理员二次确认后可对在线设备下发整机重启命令；手机无需现场确认。执行依赖设备具备所需管理权限，不把 App 进程重启作为完成整机重启。
- B26. 离线时不允许发出重启命令，不为离线设备积压待上线执行的重启任务；同一命令不得重复造成重启。
- B27. 网页区分命令发出与设备实际结果；系统拒绝或无法确认完成时不得显示已成功重启。

## 非目标

- 手动设备绑定、本机解绑及 App 内修改服务器地址。
- 配置同步中的密码、密码校验值、目录授权与设备管理身份迁移。
- 其他 App 或 Android 操作系统版本更新。
- 采集具体点击、实际触摸时长、其他 App 使用行为。
- 多设备自动共用同一份配置、按字段合并冲突。
- 离线设备重启队列、锁屏下固定秒数的远程送达保证。

| 总开关关闭后不维持事件监听 | B6 要求远程管理与使用统计独立于管控总开关；管控闹钟和短时执行服务仍遵循本地职责 |

| 不引入网络重连、上传队列 | B12、B18、B24 需要网络恢复与补传；不因此扩大系统策略失败的自动重试行为 |
| 仅本机时间，不引入跨端时钟比较 | B10–B11 增加同步配置的时间比较，既有周表仍按上海时区解释 |

```text
本机初始化完成 → 自动注册 → 独立设备身份
                              ↓
本机配置 ←─ 按保存时间整份同步 ─→ 网页配置
设备状态 / 使用会话 / 应用目录 ─→ 网页查看
在线重启 / App 升级          ←─ 网页管理员

总开关仅控制管控策略；远程管理与使用统计独立运行。
```

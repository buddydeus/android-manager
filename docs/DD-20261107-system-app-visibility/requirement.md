范围：修复共同的策略归属处理；保留现有配置、未知限制边界和中断恢复规则。

调查：OPPO现有市场/浏览器hidden=true，suspended=false，回执unknownHidden=true/ownHidden=false。市场20:36有显式UNHIDE成功；20:40再次SUSPEND成功，随后多次HIDE返回失败，21:10只记录UNSUSPEND。旧日志缺少调用前后即时读数，尚不能确认具体OEM变化时机。

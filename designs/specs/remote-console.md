# 远程管理网页

沿用已确认的 [本机简洁方向](android-manager-minimal.md)，功能语义以远程需求/技术方案为准。本轮是仓库内Vue网页和自托管部署，不发布到第三方Sites。

- 颜色：白 #FFFFFF、背景 #F4F6F8、正文 #1B2B3A、次级 #526171、动作蓝 #2563EB、错误 #B42318；分隔线表达分组，不使用装饰卡片网格。
- 字体：系统中文无衬线，时间和数字用tabular-nums；不加载外部字体或资源。
- 结构：桌面左侧设备列表、右侧详情；窄屏列表移到顶部，规则/记录/维护三页。配置切页保留草稿，换设备或退出时询问丢弃。
- 区分保存、设备接收和实际执行；使用合计只计算完整记录，缺失单列；升级和重启均呈现阶段结果。
- 复核：去除大数字营销区、装饰图与通用卡片网格；重点是设备规则与执行回执的对齐。24小时数据通过原生时间输入编辑，显示样式随浏览器区域设置。

```text
设备列表 │ 设备、在线状态、启动估算与当前版本
         │ 配置 / 使用记录 / 维护
         │ 当前页明细与明确动作
```

实际截图、配对提示词和生成方法见 [验证索引](../validation/remote-console/README.md)。

- 应用黑名单只有目录行内复选开关一处操作入口；统一保存配置，不显示额外已选应用列表。

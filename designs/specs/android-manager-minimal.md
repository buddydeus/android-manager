## Revised Direction — frontend-design

**方向：安静、清楚的本机管理工具。** 视觉依据是 Android 系统设置与每周排班表：行式结构、对齐的时刻、清晰开关、一处强调色。

1. **Subject grounding**：面向这台设备的管理员。每页只解决一个具体任务：了解执行状态、选应用、配置周表、管理密码/权限、查日志。
2. **Memory point**：周表每行的细长24小时限制轨道，蓝色段表示已配置限制时段；全天为完整蓝条，未设置为空轨道。它是信息表达，旁边始终保留文字时段。
3. **Aesthetic risk**：大幅减少独立圆角卡片，主要采用白色整块列表与轻分隔线。牺牲装饰层次，换取更紧凑可扫描的管理界面；时间轨道是唯一突出的图形元素。
4. **Detemplating changes**：删除营销Hero、绿色第二主色、英文展示字体、无用途统计和重复说明；把状态叙述改为“当前限制时段/执行结果”等明确标签，错误不被正常状态吞没。
5. **Rejected defaults**：不采用奶油陶土衬线、黑底荧光、报刊密栏、渐变及同质卡片网格。蓝色仅用于动作、选中和限制轨道，契合系统控制语境。

### 去模板化问答

| 问题 | 本轮答案 |
| --- | --- |
| 具体主题和受众？ | 单机应用管控，持有本机管理密码的管理员。 |
| 单页任务？ | 登录验证；概览判断当前效果；应用维护黑名单；时间表编辑规则；设置管理密码/权限；日志追踪失败。 |
| 色字布局源自主题？ | 原生系统字体、开关、分组设置列表和排班时间轨道，保持本机工具熟悉感。 |
| 开屏是否套用大数字Hero？ | 无。概览先展示总开关和“当前限制时段”，随后展示独立执行结果。 |
| 为什么显示数字？ | 时间是规则本身；黑名单数量是实际集合计数。均不充当装饰主标题。 |
| 字体是否随机SaaS配对？ | 否，单一系统中文字体；时刻使用等宽数字特性但不换成代码字体。 |
| 字体是否有目的？ | 中等字重、对齐时刻，体现工具的克制及确定性。 |
| 编号是否真实顺序？ | 仅初始化步骤1/2/3使用编号；普通管理页面不编号。 |
| 分隔和标签是否传达信息？ | 分组、时区、结果、失败原因各有独立语义，不加英文眉题。 |
| 唯一记忆点？ | 24小时细轨道，源自真实周表。 |
| 唯一风险合理吗？ | 低卡片化让长列表更快扫描，以留白、文本层级维持区块区分。 |
| 大胆是否集中？ | 是，周表轨道；其余页面原生列表。 |
| 名称是用户语言吗？ | 页面使用应用、限制、时间表、密码；不显示CE/DP、generation或内部回执枚举。 |
| 错误和空态如何说？ | 原因加可执行下一步；空周表提示配置，密码不可访问指向恢复入口。 |

采用系统 sans-serif（中文随系统，拉丁/数字随系统），不联网下载字体。标题24sp/32、区块18sp/26、正文16sp/24、说明14sp/20、底栏12sp/16；中等字重500，时间20sp/28，采用等宽数字。关键内容不使用12sp。4/8dp间距节奏；外边距20dp，区块24dp，行间12dp；按钮/输入圆角12dp，列表分组16dp；无常驻投影。正文/次级文字及按钮文案对比度目标≥4.5:1，图标/交互轮廓≥3:1。浅色首轮交付；深色另做完整tokens验证，不自动反转。

## Layout concept

页面标题 + 一个主要任务区域 + 分组行式内容 + 固定底部五项导航。登录/初始化不显示管理导航。手机按360–430dp适配，320dp可换行；系统字体放大时保持可滚动与48dp触控。大屏为内容最大640dp居中，不增加桌面网站视图。

```text
登录/初始化 → 概览   应用   时间表   设置   日志
                 └──────── 底部五项导航 ────────┘
时间表
  标题 + 上海时间 + 结束分钟规则
  周一                限制开关
  [       设为全天 / 全天（已选择）       ]
  [开始 09:00]          [结束 20:00]
  ────■■■■■■■■■■■■────────  24h轨道
  周二 … （其余日期纵向滚动）
  [           保存周时间表             ]
  底部导航 + 系统手势安全区
```

### 页面与状态覆盖

| 页面 | 结构、动作、边界 |
| --- | --- |
| 登录 | 顶部小型线性盾牌图标、应用管控、管理密码；一个密码框与全宽“登录”。输入框下不展示默认密码说明，不添加不存在的忘记密码入口；密码可粘贴、数字键盘。键盘弹出时内容可滚动。 |
| 初始化 | 设备管理→密码目录→设置密码的实际步骤。DO缺失页保留电脑操作说明与可选展开技术命令、“重新检查管理身份”；目录页“授权本地密码目录”；新密码及确认框，“保存新密码”。默认密码只在必要的初始化/恢复状态说明，不能重新加到普通登录框下。 |
| 密码异常 | “密码目录无法访问”+真实原因；“已有后台管控继续运行”。“重新设置密码存储”及“重新检查”；不能暗示数据被删除。 |
| 概览 | 总开关独立行；浅蓝色当前时段区（例如“当前限制时段”/“下一边界 23:00”）；执行结果、定时执行、时间设置限制分别列行；黑名单数量；底部“退出管理”。开启只代表意愿，不能显示为“全部已限制”。空表显示“尚未设置限制时段”。权限异常以就地红色区块显示原因。 |
| 应用 | 搜索名称或包名、系统应用筛选；黑名单优先，名称/包名/安装状态/开关；图标用已有真实应用图标或统一占位；暂停与隐藏结果分别说明，错误展开长内容，不能只用一个“受限”覆盖两维；保护原因、未安装、更新中明确显示；加载/空搜索保留筛选操作。黑名单切换即时提交。 |
| 时间表 | 每天一组行式结构：日期、开关、始终显示且独占一行的全天按钮、启用时的时分选择器、只读24小时轨道；全天按钮直接启用当天并填入00:00–23:59。底部固定保存按钮位于导航上方，与内容预留等高空间；未保存状态显示“有未保存的修改”。保留起止相等校验、取消不改草稿、跨日归属和上海时区。结束分钟完整包含第59秒，次分钟解除，全天标签为00:00–23:59。未设置不能被展示为全天可用，因为可能承接昨日跨日限制。 |
| 设置 | 权限分组：精确闹钟检查入口，已有能力状态；密码目录：可换行真实位置；改密分组：新密码/确认/“保存新密码”；底部红色描边“清空密码”，保留删除文件、退出管理及保留管控规则的真实影响说明，不增加退管按钮。密码错误/提交反馈靠近对应操作。 |
| 日志 | 日期输入及格式提示；全部/登录安全/配置变更/管控执行/权限异常筛选，可换行或横向滚动且不挤压；“查询”；按实际日志字段/原始文本展示时间、事件、结果，不编造详情；长错误换行；页底上一页/下一页，沿用50条分页；损坏行跳过提示必须可见。 |

时间轨道为只读，不能拖动，起止只能通过系统24小时时分选择器修改。跨日从起点到24点绘制，次日延续用文字“至次日09:00”提示；不设置的日期显示“本日未设置”，不推断昨天带来的实际状态。预览数据为演示，不代表手机当前配置；不得虚构能力已全部验证。

## Copy tone

简短中文、动作直接、状态分层。主按钮：登录 / 保存新密码 / 保存周时间表 / 查询；独立快捷按钮：周一设为全天（依日期变化）/ 周一全天（已选择）。空态：“尚未设置时间表，先为一天选择限制时段。” 错误：“定时执行不可用，请授予精确闹钟权限。” 实际失败原因优先原样展示或附详细信息。

## Interaction / engineering handoff

- 只改变表现与导航布局，沿用ManagerViewModel统一授权及现有协调入口；切页不丢认证保护，离开/锁屏清会话与日志。
- 总开关、黑名单即时提交；周表仅保存后生效，独立全天操作只改草稿。忙碌态禁用相关操作并反馈进度。
- 固定底栏每项图标+中文，点击区域≥48dp；不使用emoji。可使用原生Material矢量图标，不画装饰图。
- TalkBack朗读日期、动作及状态；开关绑定说明；轨道旁有完整文本等价物，不只用颜色表达。
- 动效仅开关、原生ripple和120–180ms状态反馈；尊重系统减少动画；无进场飞入或闪烁。
- 错误不被成功状态盖住，不改现有密码/配置/设备策略/日志语义；保留系统选择器安全窗口设置。
- 未保存周表的返回/切页需保留草稿或明确提示；具体方案在实现时沿用现有生命周期约束，不静默保存。

## Implementation Notes

实现顺序：主题tokens→页面框架/底栏→登录/初始化→概览→应用列表→周表→设置/日志→错误与大字体验。当前只产出规范、提示词、预览；待用户选择1后实施。当前没有新增统计、云服务、批量规则、退管或额外权限功能。

## 预览复核与交付记录

- 使用内置 ImageGen，最终完整提示词位于上述两份配对文档；未使用CLI/API回退。
- 核心页面PNG为1475×1066，管理页面PNG为1476×1066。目视确认：六页齐全、五项导航、登录无默认密码说明、全天按钮独立一行且关闭日仍可见、保存栏与导航不重叠。
- 图像生成存在视觉近似：日志“成功”被渲染为绿色，正式实现使用正文色；概览中静态状态行出现右箭头，正式实现去掉非导航行箭头；轨道的细分钟精度与配色以SSOT为准。
- 设计未经过真实设备、TalkBack或动态字体验证；这些检查属于后续实现验收，不能以PNG替代。
- 已进行克制复核：不添加装饰性统计、额外品牌标语及卡片阴影；保留真实操作所需说明。
